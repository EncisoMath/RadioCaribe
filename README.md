# RadioCaribe

Reproductor de radio dedicado para Moto G3 (LineageOS 16 / Android 9).

- Interfaz landscape estilo tuner de carro
- Tema claro y oscuro
- Última emisora recordada
- Autoplay
- Anterior / Play-Pausa / Siguiente
- Radios online del Caribe colombiano

El APK se compila automáticamente con GitHub Actions.
